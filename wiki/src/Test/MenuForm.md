# MenuForm regression suite
## Purpose
Pure editor validation tests in test/Validation/MenuFormTest.pudu.
## Algorithm
Validate raw nested drafts, inspect typed documents and indexed errors. Exercise decimal/cap/overflow boundaries, null/free distinctions, publication limits, stable/duplicate UUIDs, enums and declared/unknown allergens. Refilled listings retain identity and unknown facts.
## Negative Logic
No live calls, real food records, credentials or mutation of submitted drafts.
## Grill Log
Resolved: fictional inputs are test-only. Database rollback and race tests cover authorization/revisions separately. Pure validation tests prevent price overflow and discarded raw input; browser editor verification follows once controls/routes exist.
Resolved review: a nested UTF8 example is compared with an actual development PostgreSQL JSONB byte count; a compact document that fits but exceeds the spaced representation is refused by the byte calculation.
