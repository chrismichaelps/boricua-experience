# App.Handlers.Participation

> /** @App.Handlers.Participation.Registrations — joining, deciding, saving, reacting, reporting */

## Purpose

Registers one mediator handler per kind of joining, deciding, saving, reacting, reporting; each lifts a service result into the mediator's outcome.

## Interface

### Signatures

```pudu
export fn registrations(kinds: &Messages.Kinds, runtime: &Runtime.Runtime) -> Array[Registration.Registration]
```

### Linkage

- **Requires:** `pudu-lang-mediator`, [[src/App/Messages]], [[src/Services/Participation]].
- **Consumed by:** [[src/App/Assembly]].

## Algorithm

For each of join, withdraw, decide, queue, save, react, report, activity: `Registration.handler(&kinds.<kind>, |message, context| Messaging.lift(Service.call(...)))`.
