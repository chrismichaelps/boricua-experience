# View.Components.Uploader
## Purpose
Shared native file picker.
## Interface
render(frame,action,kind,accept,label,labelled) returns H.Node; PHOTO_TYPES names supported input photos.
## Algorithm
Render CSRF token, required labeled file input, optional document label, no-script explanation, upload submit control and live status. Existing media-upload enhancement resizes images, reserves, uploads and requests verification; unsupported formats fail visibly.
## Negative Logic
No client confirmation authority, invented records, direct table grants, paid resources or write retries.
## Grill Log
Resolved: Shared labeled native file picker for owner/organizer image and menu document uploads; no-script notice, explicit rights and bounded input, live status and existing asynchronous submit feedback.
