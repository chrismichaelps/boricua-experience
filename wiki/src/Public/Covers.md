# Covers

## Purpose

Restrained flat category fallback illustrations for events without photos.

## Interface

public/assets/covers/*.svg retains all existing category paths and icon semantics.

## Algorithm

Replace repeated gradient icon textures with quiet tonal shapes and a single category symbol. User event photos remain unchanged.

## Negative Logic

No secret data, persistent animation loops, hidden unenhanced content or new remote runtime dependencies.

## Edge Cases

Reduced motion, interrupted transitions, unsupported enhancement, keyboard focus, narrow screens, no scripts and returning cached clients.

## Depth

MEDIUM: progressive presentation; vendor is an external library boundary.
