# Public.A11y

## Purpose

`a11y-boot.js` is a small classic script in the head that owns the settings model (`window.bxA11y`): it sanitizes what is stored under `bx-a11y`, and applies classes and CSS variables on `<html>` before first paint, never touching other classes. `features/a11y.js` drives the panel, profiles, steppers, the color mode, the pointer- and focus-following reading guide and mask, the page map, Alt+A, and per-visit hiding. `a11y.css` styles the launcher and panel and holds every page adjustment; text size uses `zoom` on the content and footer so layouts scale with the text. The toolbar itself has no animation. `bx:a11y` is dispatched on each change; `a11y-mute` silences app sounds.

Tests: `scripts/a11y-test.mjs`.
