# Public.Illustrations

## Purpose

Glossy, emoji-style SVG illustrations in the cotorra palette, each with its own gentle loop embedded in the file and a reduced-motion guard: the waving cotorra on a flamboyán branch (hero), cotorra with heart eyes, coquí, Puerto Rican flag, shield, heart, bulb, seal, thumbs up, search, ticket, party popper, rocket, key, star and envelope. Generated from shared gradient and gloss primitives so new ones match.
