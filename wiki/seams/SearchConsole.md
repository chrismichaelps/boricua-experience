# Search Console

## Production property
The Domain property `sc-domain:boricuaexperience.com` is verified through an apex TXT record on the existing active Cloudflare Free zone. Retain the verification record; no Google DNS-account delegation or additional billable service is needed. Existing hosting, mail and verification records are preserved.

## Discovery contract
Submit the canonical production sitemap at `https://boricuaexperience.com/sitemap.xml`. The application generates it from public catalog/publication data; private account, activity, notification, admin and API routes remain excluded from crawler entry points. Root robots.txt advertises the sitemap. Domain ownership covers HTTP/HTTPS and subdomains, while canonical page URLs remain HTTPS on the apex hostname.

## Verification evidence
2026-10-12: Google confirmed domain ownership and sitemap status “Correcto” with 192 discovered pages. URL inspection reports the homepage already indexed; the live test reports the URL available to Google and indexable. The subsequent homepage indexing request was accepted into the priority crawl queue. Production home/category/town pages have one title and H1, descriptions, canonical URLs, index/follow directives and parseable structured data. This is technical discoverability evidence, not a ranking or per-page indexing guarantee. Manual Actions and Security Issues both report no detected problems. Canonical search and map pages also advertise index/follow. Search Console report aggregation is still processing on this new property.

## Operations
Inspect changed canonical URLs and use bounded indexing requests when useful. Search Console determines crawl/index status; submitting a sitemap or an indexing request does not guarantee ranking. Do not submit authentication/action/filter duplicates as independent properties. Sitelinks are generated by Google; maintain clear navigation, descriptive titles and internal links rather than claiming a configurable sitelinks list.

Preserve Free plans, secrets and production records. No unnecessary analytics scripts, paid subscriptions, indexing API shortcuts or unverified success claims.
